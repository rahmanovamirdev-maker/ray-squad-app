# ДИАГНОСТИКА И ИСПРАВЛЕНИЕ TELEGRAM НА PRODUCTION

## Быстрые команды для проверки на боевом сервере

### 1. Запустить полную диагностику
```bash
cd /путь/к/боевому/сайту
python3 diagnose_telegram.py
```

Этот скрипт проверит:
- ✅ Установлена ли библиотека python-telegram-bot
- ✅ Правильность токена бота
- ✅ Подключение к Telegram API
- ✅ Наличие updates (кто-то писал боту?)
- ✅ Сохраненные chat_id в БД

### 2. Проверить что библиотека установлена
```bash
pip list | grep telegram
# Должно показать: python-telegram-bot    xx.x
```

Если нет — установить:
```bash
pip install python-telegram-bot
```

### 3. Проверить токен бота
```bash
echo $TELEGRAM_BOT_TOKEN
# Должно показать токен вида: 1234567890:ABCDefGHI...
```

Если не показывает или пусто:
```bash
export TELEGRAM_BOT_TOKEN="8605769417:AAGZYyF8tOvhWwEqq8iO8SC8iCK08DwEZh0"
# Добавить в .bashrc или .env файл для постоянства
```

### 4. Ручной тест отправки
```bash
# Тест для конкретного пользователя
python3 test_telegram.py @flowxz

# Тест с известным chat_id
python3 test_telegram.py @flowxz 123456789
```

## Частые проблемы и решения

### ❌ Проблема: "Библиотека не установлена"
**Решение:**
```bash
pip install python-telegram-bot
systemctl restart ваш-сервис
```

### ❌ Проблема: "Updates пусты (никто не писал боту)"
**Решение:**
1. Найди бота в Telegram (@имя_бота)
2. Напиши ему `/start`
3. Повтори отправку формы

### ❌ Проблема: "Пользователь не найден в диалогах бота"
**Причина:** Человек не написал боту `/start` ПЕРЕД заполнением формы

**Решение:**
1. Попроси его написать боту `/start`
2. Дождись пока он это сделает
3. В админке нажми повторно "Одобрить" или "Отклонить"
4. На этот раз уведомление должно дойти

### ❌ Проблема: "403 Forbidden" или "Invalid token"
**Решение:**
Проверь токен:
```bash
curl "https://api.telegram.org/bot8605769417:AAGZYyF8tOvhWwEqq8iO8SC8iCK08DwEZh0/getMe"
```

Должен вернуть JSON с информацией о боте. Если ошибка — токен неправильный.

### ❌ Проблема: "Can't initiate conversation with a user"
**Причина:** Telegram не позволяет ботам писать первыми незнакомым людям

**Решение:**
Это нормально! Пользователь ДОЛЖЕН написать боту первым (`/start`).
В форме на сайте уже есть подсказка об этом.

## Как работает система

1. **При подаче заявки** (сразу):
   - Форма отправляется на `/api/public-scout-application`
   - Бот ищет chat_id в updates по username
   - Если находит → отправляет "ЗАЯВКА ПОЛУЧЕНА!" + сохраняет chat_id в БД
   - Если не находит → сохраняет только заявку

2. **При одобрении/отклонении** (админ в панели):
   - Админ нажимает кнопку
   - Запрос идет на `/api/admin/scout/<id>/approve` или `/reject`
   - Бот использует сохраненный chat_id (если есть) или ищет заново
   - Отправляет финальное решение

3. **Сохранение chat_id**:
   - При первой успешной отправке chat_id сохраняется в `scout_join_application.telegram_chat_id`
   - Последующие отправки используют этот chat_id напрямую (быстрее и надежнее)

## Логи для отладки

### Посмотреть логи Flask
```bash
journalctl -u ваш-flask-сервис -n 100 --no-pager
```

Ищи строки с:
- `✅ Telegram уведомление отправлено`
- `❌ Ошибка Telegram для`
- `Telegram notifications disabled`

### Включить debug логи (если нужно)
В app.py добавь в начало:
```python
logging.basicConfig(level=logging.DEBUG)
```
