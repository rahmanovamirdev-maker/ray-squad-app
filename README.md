# 🌟 Ray Squad - Система управления анкетами

Полнофункциональный веб-сайт для управления анкетами кандидатов с базой данных, авторизацией и экспортом.

🌐 **Готово к production с собственным доменом!**

## 🎯 Возможности

✅ **Добавление анкет** - Заполняйте информацию о кандидатах  
✅ **Просмотр списка** - Видьте всех добавленных кандидатов  
✅ **Экспорт в TXT** - Скачивайте полный отчет одним кликом  
✅ **Удаление записей** - Управляйте базой данных  
✅ **Автосохранение** - Всё сохраняется в базе данных  

## 📋 Поля анкеты

- **ФИО** (обязательное)

- **Телефон** (обязательное)

## 🚀 Быстрый старт

### Development (локально)

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python app.py
```

3. Откройте браузер:
```
http://127.0.0.1:5000
```

### Production (на сервере)

1. Установите gunicorn:
```bash
pip install gunicorn
```

2. Запустите с gunicorn:
```bash
gunicorn app:app --bind 0.0.0.0:5000 --workers 4
```

3. Для Heroku используйте deploy скрипт:
```bash
chmod +x deploy.sh
./deploy.sh
```

📖 **Подробное руководство**: [DEPLOYMENT_GUIDE.md](DEPLOYMENT_GUIDE.md)

## 💾 База данных

Все данные сохраняются в `database.db` (SQLite база данных). 
База создается автоматически при первом запуске.

## 📥 Экспорт данных

Нажмите кнопку **"⬇️ Скачать отчет (TXT)"** чтобы:
- Скачать TXT файл со всеми анкетами
- Файл автоматически именуется с датой и временем
- Можно открыть в любом текстовом редакторе

## 🛠️ API Endpoints

- `GET /` - Главная страница
- `POST /api/add-applicant` - Добавить новую анкету
- `GET /api/applicants` - Получить список всех кандидатов
- `DELETE /api/delete/<id>` - Удалить анкету
- `GET /download-report` - Скачать отчет в TXT

## ⚙️ Технологический стек

- **Backend**: Python Flask
- **Database**: SQLite
- **Frontend**: HTML5, CSS3, JavaScript
- **Styling**: Gradient Design с Bootstrap элементами

## 📝 Примечания

- Приложение использует развертывание на localhost
- Для промышленного использования замените `debug=True` на `debug=False`
- Все данные хранятся локально в database.db

## 🔒 Безопасность

Для более безопасного использования в production:
1. Измените `debug=False` в app.py
2. Используйте переменные окружения для конфиденциальных данных
3. Добавьте аутентификацию для доступа к функциям экспорта
4. Используйте HTTPS

## 📞 Поддержка

Если возникнут проблемы:
1. Убедитесь, что Python установлен
2. Проверьте, что все зависимости установлены
3. Убедитесь, что порт 5000 не занят другим приложением
