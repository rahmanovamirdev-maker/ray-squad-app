# 🚀 Инструкция деплоя на боевой сервер

## Проблема
На боевом сервере ошибка при загрузке анкет скаутеров, потому что БД не содержит новых колонок (status, approved_by, rejected_by, reviewed_at).

## Решение - Выполнить эти команды на сервере по SSH:

```bash
# 1. Перейти в директорию проекта
cd /var/www/ray-squad-app

# 2. Получить последний код с GitHub
git pull origin main

# 3. Активировать виртуальное окружение
source venv/bin/activate

# 4. Установить зависимости (если необходимо)
pip install -r requirements.txt

# 5. Запустить миграцию БД - ВАЖНО!
python migrate_scouts.py

# 6. Перезагрузить Flask приложение
sudo systemctl restart ray-squad
```

## Что делает миграция?
Скрипт `migrate_scouts.py` добавляет 4 новые колонки к таблице `scout_join_application`:
- `status` (pending, approved, rejected)
- `approved_by` (имя админа который одобрил)
- `rejected_by` (имя админа который отклонил)  
- `reviewed_at` (время рассмотрения)

## Проверка результата
После выполнения команд выше, перейти на админ панель → вкладка "Скаутеры" и проверить что анкеты загружаются без ошибок.
